# PAL-DEMOD

PAL-DEMOD — инструмент для поиска аналогового видео в спектре сигнала и его показа. На вход подается бинарный файл, содержащий FM-модулированный сигнал. PAL-DEMOD подбирает наилучшую частоту для демодуляции и пытается найти в сигнале аналоговое видео в формате PAL, которое, в случае успеха, дополнительно проходит очистку от шумов. Перед началом работы необходимо указать частоту дискретизации и формат, в котором был записан сигнал. Формат может быть одним из следующих:

* Complex 8-bit signed
* Complex 16-bit signed
* Complex 32-bit float
